> 一款基于 **Jetpack Compose + Google ML Kit + 国内永久免费大模型** 打造的现代化智能阅读与写作伴读 Android 应用。  
> 告别死板翻书与机械背诵，面向全年龄段读者自适应生成通识导学，支持篇名自然语言直达、离线 OCR 拍照识书、全景五维拆解、逐句文白精讲、双向语音互动与多节点国内网络容错升级。

---

## 🌟 核心功能特性

### 1. 篇名自然语言直达 (免死板翻书)
- **告别传统本地静态教材库**：以往学习软件必须先选“几年级几单元”，遇到版本不一致便无法使用。
- **AI 智能理解召回**：输入或语音说出想读的课文名、名篇或篇章特征（如“三年级上册第14课”、“观沧海”、“小石潭记”、“赤壁赋”、“匆匆”），AI 导师自动召回标准课文原文并开启深度导读。

### 2. 多模态采集：离线拍照识字与双向语音
- **离线拍照识字 (Google ML Kit)**：遇到课外书、报纸试卷，点击【拍书籍】对准页面拍照，纯本地离线 OCR 秒级提取文字，不耗流量，隐私安全；
- **双向语音互动**：支持语音说出篇名或提问，集成 Android 原生 TTS 离线标准普通话伴读，并提供 **0.5x ~ 1.5x 语速平滑调节**。

### 3. 全景五维多维导读 (自适应全年龄段深度)
系统根据输入文本的体裁（文言文、古典诗词、现代散文、说明文、议论文）智能匹配分析深度：
- **【知人论世·背景探寻】**：深度剖析作者身世遭遇、创作心境与时代底蕴；
- **【核心立意·三步推导】**：直观推导文章情感主旨，引导读者领悟深层思想；
- **【重要知识点·核心考点全览（全量必背与记忆清单）】**：全量梳理字词音形义、多音字、成语、通假古义、常考出题点、名句默写清单与文学常识，全量穷尽，拒绝举例；
- **【技法说透·写作借鉴】**：拆解篇章结构逻辑，提供可以直接仿写套用的写作实战技巧；
- **【分段独立点读】**：全景导读卡片按章节拆分，右上角均设有【🔊 听此段】按钮，指哪听哪。

### 4. 逐句精讲与文白全景对照 (默认关闭，按需开启)
- **按需呈现**：日常阅读现代文时保持界面清爽，故该功能**默认处于关闭状态**；
- **古诗文神器**：当阅读文言文、生僻古诗词时，一键打开【逐句精讲与文白对照】开关，AI 将逐句提供原文与现代汉语严格对照、通假字释义与疑难词句详解。

### 5. 自由多轮伴读问答室
- 主界面下方常驻互动问答室，针对文章理解不透、段落修辞有疑问、需要根据课文构思作文提纲时，可随时追问导师，支持多轮上下文记忆。

### 6. 大模型自主可控 (永久免费 / 自定义扩充)
- **开箱零成本**：预设国内永久免费调用的智谱 BigModel `glm-4-flash` 大模型，注册账号即可终身免费使用；
- **解耦通用协议**：底层遵循标准 OpenAI API 规范。在【⚙️ 设置】中，支持自由填入任何第三方 Base URL 与模型名称（如 DeepSeek、通义千问、Kimi 或自建反向代理），保存即生效，无需重新编译发版。

### 7. 国内网络延时容错与手动一键升级
- **国内节点容错**：针对国内访问 GitHub 容易超时的问题，内置**官方 API + 备用镜像源多节点轮询**；
- **双通道升级下载**：新版本弹窗同时提供【🚀 高速下载】（国内加速通道）与【🌐 官方源】，彻底解决国内下载卡顿问题；
- **数据永久留存**：覆盖安装更新后，本地保存的 API Key、模型设置、自定义语速均完好无损，不会丢失。

## ⚙️ 模型配置与使用说明

点击应用右上角的 **【⚙️ 设置】** 图标，即可进行个性化配置：

### 1. 官方推荐（零成本永久免费）
1. 浏览器访问智谱大模型开放平台：`https://open.bigmodel.cn/`；
2. 免费注册账号，进入控制台菜单【API Keys】创建专属密钥；
3. 在 App 设置弹窗中填入：
   - **API 接口地址 (Base URL)**: `https://open.bigmodel.cn/api/paas/v4`
   - **模型名称 (Model)**: `glm-4-flash`
   - **API Key**: 粘贴您生成的密钥（如 `xxxxxx.yyyyyy`）
4. 点击【保存生效】即可终身免费使用。

### 2. 扩充接入其他第三方大模型
本应用支持任何符合 OpenAI 规范的 API 平台：

| 平台名称 | 接口地址 (Base URL) | 推荐模型名 (Model) |
| :--- | :--- | :--- |
| **智谱 BigModel** (默认推荐) | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` (永久免费) |
| **DeepSeek** | `https://api.deepseek.com` | `deepseek-chat` / `deepseek-reasoner` |
| **阿里通义千问 (DashScope)** | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-turbo` / `qwen-plus` |
| **自建 One-API / 反向代理** | 您的自定义反代地址 | 对应模型名 |

## 🔄 升级与数据安全说明

1. **手动检测更新**：
   - 打开【⚙️ 设置】，滑至底部找到【软件版本】卡片；
   - 点击【检查更新】，系统将通过内置多节点自动比对 GitHub 最新发布；
   - 若有新版本，弹窗展示更新说明，点击【🚀 高速下载】即可通过国内镜像秒速下载 APK。
2. **数据持久化防丢机制**：
   - 所有的 API Key、接口地址、模型名、字号及语速均保存在 Android 系统受保护的私有存储（`SharedPreferences`）中；
   - 覆盖安装新版本 APK 时，数据自动延续保留，**绝不会发生升级后配置清空的问题**。

## 🚀 自动化构建与发布 (CI/CD)

本项目配置了基于 GitHub Actions 的一键编译与发布工作流：

1. 打开 GitHub 仓库页面，切换到 **Actions** 选项卡；
2. 在左侧工作流列表中选择 **【手动编译并发布 Release】**；
3. 点击右侧 **【Run workflow】**：
   - **version**: 输入发布版本号（如 `v1.0.0`）；
   - **release_notes**: 填入本次更新内容说明；
4. 构建脚本会自动执行代码检查、编译打包，并在 **Releases** 页面自动发布新版本并挂载规范命名的 APK 安装包（`StudentReadingAssistant-v1.0.0.apk`）。

## 🛠️ 技术架构

- **UI 框架**: Android Jetpack Compose + Material 3
- **开发语言**: Kotlin 1.9.22 (JVM 17 Target)
- **架构模式**: MVVM + StateFlow 响应式单向数据流
- **端侧 OCR**: Google ML Kit Text Recognition (中文离线增强引擎)
- **语音引擎**: Android 系统原生 TTS 语音伴读合成 + 语音输入 Recognizer
- **网络通信**: OkHttp 4.12.0 + Server-Sent Events (SSE) 流式打字机响应
- **构建环境**: Gradle 8.4 + Android Gradle Plugin 8.2.2 + JetBrains 全球高速 CDN
